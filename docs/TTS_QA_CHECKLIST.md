# TTS 中英适配与验收清单

目标：确保在目标机器上，中文（zh-CN）与英文（en-US）均可通过“Piper/系统 TTS/回退”可靠播报。

## 验收矩阵

| 用例 | 引擎路径 | 期望 | 备注 |
|---|---|---|---|
| 英文短句（Hello, welcome） | Piper→System→Web | 正常播报、不中断 | 若未打包 Piper 英文模型，则走系统 |
| 中文短句（你好，欢迎） | Piper→System→Web | 正常播报、语速可调 | 若无 Piper 中文模型，则走系统 |
| 音素讲解（/θ/） | Sprite→System→Web | 声音一致、无爆音 | 载体音节策略有效 |
| 快速连续播放 | 同上 | 不重叠/不抢占（或可配置） | 队列/串行化 |
| 速率/音调 | 同上 | 范围 0.5–2.0 有效 | 边界值不过载 |

## 手工测试步骤

1) 列表与能力
- 调用 tts_list_voices()，确认 'en' 与 'zh' 语言的声音均可见（至少 1 个）
- 调用 tts_capability()，确认 system.ok=true；若打包了 Piper，piper.ok=true

2) 英文播报
- speak('Hello', { lang: 'en-US' }) → 应成功
- 调整 rate/pitch（0.8/1.2），听感变化明显

3) 中文播报
- speak('你好，欢迎来到课堂', { lang: 'zh-CN' }) → 应成功
- 若 Piper 中文模型缺失 → 应自动使用系统 TTS

4) 回退验证
- 临时禁用 Piper（配置开关）→ 英文/中文均应回退到系统 TTS
- 在浏览器开发模式下禁用 Tauri → Web Speech 可播报（仅开发）

5) 课程/音素
- 随机点击 10 个音素卡片 → 播放成功，策略= sprite
- 禁用 sprite（临时）→ 回退到系统 TTS，载体音节可懂

## 边界与容错

- 文本长度 > 200 → 拒绝或截断
- 文本包含控制字符 → 过滤换行/制表等
- 并发 5 次调用 → 应串行或后发覆盖前发（按需求）

## 性能与资源

- Piper 运行时：首次加载延迟 < 1s（取决于模型）；短句合成 < 500ms
- 资源体积：每个 Piper 模型 20–100+MB；总装包大小评估

## 记录与诊断

- 统一返回 { ok, engine, lang, voiceId, error? }
- 将关键错误写入前端日志，便于定位：无语音、模型路径无效、音频播放失败
