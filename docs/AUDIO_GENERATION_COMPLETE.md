## 🔧 进阶配置

### 调整音质

编辑 `scripts/generate-phonemes.sh` 修改参数：

```bash
# 语速 (80-200 wpm)
espeak-ng -s 100 ...  # 更慢
espeak-ng -s 150 ...  # 更快

# 音高 (0-99)
espeak-ng -p 40 ...   # 更低
espeak-ng -p 60 ...   # 更高

# 语音选择
espeak-ng -v en-gb ... # 英式英语
espeak-ng -v en-scottish ... # 苏格兰英语
```

### 手动替换音素

如果某个音素发音不理想：

1. 录制/下载对应的 `.wav` 文件（24kHz, 单声道）
2. 放入 `tmp/phoneme-audio/vowels/` 或 `consonants/`
3. 文件名必须匹配音素ID（如 `v1.wav`）
4. 重新运行打包：

```bash
cd tmp/phoneme-audio/vowels
audiosprite \
  --output ../../../public/assets/audio/phonemes-vowels \
  --export mp3 \
  --format howler \
  --channels 1 \
  --samplerate 24000 \
  *.wav
```

## 🐛 已知问题

### Sox 警告

生成过程中出现的警告（`rate clipped X samples`）是**正常现象**，不影响音质。

这是因为某些音素（如长元音、擦音）的音量略高，Sox 在采样率转换时进行了自动限制。

**解决方案**（可选）：
```bash
# 降低 espeak-ng 音量
espeak-ng -a 180 ...  # 从 200 降到 180
```
