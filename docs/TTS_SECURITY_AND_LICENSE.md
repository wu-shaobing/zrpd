# TTS 安全与许可

## 安全边界

- 仅运行受控引擎：系统语音（tts-rs 内部 API）、Piper（受控路径/参数）。
- 禁止任意命令拼接：若采用 sidecar 形式，固定可执行路径与参数模板；不暴露自由文本到命令行（通过 stdin 传入）。
- 输入限制：
  - 文本最长 200 字符；过滤控制字符（\r, \n, \t 等）。
  - 仅允许 UTF-8；异常字符替换或拒绝。
- 资源路径：模型文件仅从应用资源目录读取，不接受用户提供的任意路径。

## 许可与第三方归属

- tts-rs: 参考仓库 LICENSE。
- Piper 引擎与模型：各自许可证不同（多数为 CC-BY/CC-BY-SA/MIT 等），需：
  - 在 `NOTICE` 或 `About` 页列出模型名称、来源链接、许可文本。
  - 如需再分发（打包进应用），确认许可证允许。

## 数据隐私

- 不上传文本、不记录音频内容；仅记录必要的技术指标（引擎、耗时、是否成功）。
- 调试日志默认关闭，必要时以开关启用，并避免包含用户生成内容。

## 审计清单

- [ ] tts-rs 仅通过 API 调用，无 shell。
- [ ] Piper 仅从受控目录加载模型；若使用 sidecar，命令行参数固定且不含用户文本。
- [ ] 文本过滤与长度限制在前后端均生效。
- [ ] License/NOTICE 完整，包含模型来源与许可。
