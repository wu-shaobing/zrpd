# start.command 启动脚本使用指南

## 📖 概述

`start.command` 是为 macOS 用户设计的一键启动脚本，提供了最友好的项目启动体验。双击即可自动完成所有启动准备工作并打开应用。

## ✨ 功能特性

### 1. 智能环境检查
- ✅ 自动检测 Node.js 和 npm 是否已安装
- ✅ 显示当前版本信息
- ✅ 未安装时给出清晰的安装提示

### 2. 自动依赖管理
- ✅ 检测 `node_modules` 目录是否存在
- ✅ 自动安装缺失的依赖
- ✅ 检测 `package.json` 更新并自动重新安装
- ✅ 显示安装进度和结果

### 3. 端口冲突处理
- ✅ 自动检测端口 1420 占用情况
- ✅ 显示占用进程的 PID
- ✅ 可选择终止占用进程
- ✅ 避免启动失败

### 4. 优雅启动流程
- ✅ 启动 Vite 开发服务器
- ✅ 等待 3 秒后自动打开浏览器
- ✅ 智能等待服务器就绪
- ✅ 失败时给出明确提示

### 5. 用户体验优化
- ✅ 彩色终端输出，界面友好
- ✅ 清晰的步骤提示和进度显示
- ✅ 完善的错误处理和降级方案
- ✅ 支持 Ctrl+C 优雅退出
- ✅ 自动定位到脚本所在目录

## 🚀 使用方式

### 方式 1：Finder 双击启动（推荐）

1. 在 Finder 中找到项目根目录
2. 找到 `start.command` 文件
3. 双击文件
4. 终端窗口会自动打开
5. 脚本自动执行所有启动步骤
6. 浏览器自动打开应用

**优点**：
- 最简单直观
- 无需记住命令
- 适合非技术用户
- 类似普通应用的启动方式

### 方式 2：终端直接运行

```bash
cd /path/to/zrpd
./start.command
```

**优点**：
- 在当前终端窗口运行
- 可以看到完整输出
- 适合开发调试

### 方式 3：使用 bash 执行

```bash
bash start.command
```

**优点**：
- 不需要可执行权限
- 适合权限受限环境

│   └── print_info()      # 信息提示
├── 环境检查
│   ├── check_node()      # Node.js 检查
│   └── check_npm()       # npm 检查
├── 依赖管理
│   ├── check_dependencies()    # 检查依赖

### 关键技术点

#### 1. 目录定位
```bash
SCRIPT_DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
cd "$SCRIPT_DIR" || exit 1
```
- 支持双击和终端两种运行方式
- 自动切换到脚本所在目录

#### 2. 环境检测
```bash
if ! command -v node &> /dev/null; then
    print_error "未检测到 Node.js"
    exit 1
fi
```
- 使用 `command -v` 检测命令是否存在
- 失败时给出明确的安装提示

#### 3. 依赖检查
```bash
if [ ! -d "node_modules" ]; then
    install_dependencies
elif [ "package.json" -nt "node_modules" ]; then
    install_dependencies
fi
```
- 检查 `node_modules` 目录
- 比较 `package.json` 修改时间
- 智能决定是否需要重新安装

#### 4. 端口检查
```bash
if lsof -Pi :1420 -sTCP:LISTEN -t >/dev/null 2>&1; then
    PID=$(lsof -ti :1420)
    # 提示用户是否终止
fi
```
- 使用 `lsof` 检查端口占用
- 获取占用进程的 PID
- 可选择终止进程

#### 5. 浏览器打开
```bash
(sleep 3 && open_browser) &
```
- 后台进程延迟 3 秒
- 使用 `curl` 检查服务器就绪
- 最多重试 10 次
- 使用 `open` 命令打开浏览器

#### 6. 信号处理
```bash
trap cleanup INT TERM
```
- 捕获 Ctrl+C 信号
- 优雅退出，清理资源

## 💡 常见问题

### Q1: 双击后没反应？
**A**: 检查文件权限：
```bash
chmod +x start.command
```

### Q2: 提示"未检测到 Node.js"？
**A**: 需要先安装 Node.js：
- 访问 https://nodejs.org/ 下载安装
- 或使用 Homebrew: `brew install node`

### Q3: 端口 1420 被占用？
**A**: 脚本会自动提示，可以选择：
- 输入 `y` 终止占用进程
- 输入 `n` 取消启动，手动处理

### Q4: 浏览器没有自动打开？
**A**: 手动访问 http://localhost:1420

### Q5: 如何停止服务器？
**A**: 按 `Ctrl+C` 即可优雅退出

### Q6: 依赖安装失败？
**A**: 可能原因：
- 网络问题：检查网络连接
- 权限问题：使用 `sudo npm install`
- 缓存问题：清理缓存 `npm cache clean --force`

### Q7: 首次运行很慢？
**A**: 首次需要安装依赖，大约需要 2-5 分钟，这是正常的。
