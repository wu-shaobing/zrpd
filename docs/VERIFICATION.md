## ✨ 功能亮点

1. **3D翻转效果**：流畅的卡片翻转动画
2. **智能交互**：按钮点击不触发翻转
3. **本地音频**：所有音频本地生成，离线可用
4. **详细讲解**：背面包含完整的发音指导
5. **音频缓存**：避免重复加载，提升性能
