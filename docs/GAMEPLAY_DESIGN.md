# 玩法设计与交互（Gameplay Design）

## 主要板块

1. 欢迎/引导（动画+圆形字母）
2. 元音学习（A/E/I/O/U：音标+示例词+播放按钮）
3. 辅音学习（栅格展示多个辅音及读音）
4. 字母组合游戏（卡片翻转配对，得分、重置、洗牌）
5. 国际音标小课堂（48 音标总览）
6. 学习成果（分数+已掌握字母展示）
7. 规则总览（手风琴 details/summary）

该结构来自 `/Users/wushaobing911/Desktop/zrpd/自然拼读.html`，在桌面端保持一致。

## 交互细节

- 卡片翻转：点击或键盘（Space/Enter）触发；首次翻转且正确时加分
- 重置：恢复正面、清除 `scored` 标记、重新洗牌
- 进度条：滚动更新（scrollY / (文档高度 - 视口高度)）
- 动画：Hover 提升、渐显、Reduced Motion 兼容

## 语音播放

- 按钮关联 phoneme 与示例词，通过 useSpeech 播放
- 语速、音调在合理范围内可配置
- 声音设备不可用时给出提示或静默降级

## 键盘与无障碍

- 所有卡片 `tabIndex=0`，`aria-label` 描述
- Enter/Space 触发翻转；视觉焦点明显

## 评分与成就

- 每张卡片 data-points（如 5 分）
- 首次正确翻转加分；重复翻转不再累计
- 学习成果区展示当前分数与掌握字母

## 扩展玩法（可选）

- 时间挑战/连击奖励
- 难度分层：基础→进阶→挑战
- 题库随机化：来自 data JSON
